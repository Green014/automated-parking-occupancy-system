# Paper Collection Plan

## Search sources

- CVF Open Access: CVPR, ICCV, ECCV.
- OpenReview: ICLR, NeurIPS, ICML.
- ACM Digital Library / project pages: SIGGRAPH and SIGGRAPH Asia.
- arXiv only as a backup for locating PDFs or project pages; venue metadata should be verified through official sources when possible.

## Search queries

- parking lot occupancy detection
- parking space detection overhead camera
- surveillance vehicle detection
- multi-object tracking vehicle surveillance
- multi-object tracking in low light
- real-time object detection open vocabulary
- adverse weather object detection
- domain generalization multi-object tracking
- weather-aware visual perception
- RAW object detection diverse conditions

## Screening procedure

1. Build a broad candidate list from official venue repositories.
2. Keep papers from 2024-2025 first.
3. Score each paper by relevance to:
   - detection
   - tracking
   - weather/lighting robustness
   - real-time deployment
   - generalization to new cameras/scenes
4. Select at least six core papers for the final review.
5. Keep extra candidate papers as auxiliary references.

## Local storage

- PDFs: `literature_review/papers/`
- Metadata: `literature_review/metadata/`
- Notes: `literature_review/notes/`
- Final draft: `literature_review/review_draft.md`
- Comparison table: `literature_review/paper_comparison_table.md`
