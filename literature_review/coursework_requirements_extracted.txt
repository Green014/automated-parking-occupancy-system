COURSEWORK PROJECT: Computer Vision System Design and 
Evaluation 
As part of the coursework, each student is required to select, research, and implement a project 
based on Computer Vision, applying concepts and techniques learned in class \online. This 
project is intended to enhance your understanding of real -world computer vision systems and 
advance practical skills in system design, implementation, and performance evaluation. 
  Project Topic Selection 
 
✓ Projects must be based on a problem for which a suitable dataset is easily available or 
can be acquired/created with reasonable effort. 
✓ Each group must work on a unique topic. 
✓ A shared Excel sheet will be provided to register your selected topic. 
✓ The deadline to submit the selected topic is 13th May 2026 via provided link CSC 3014 
Project Title Submission.xlsx 
✓ Do not change any setting or edit other group details. 
 
 Project Components 
Part I: Literature Review (20%) 
Conduct a thorough literature review focusing on: 
✓ Existing computer vision systems or algorithms relevant to your selected topic. 
✓ Performance metrics commonly used in the field. 
Your review should help you: 
✓ Understand the objectives and context of the problem. 
✓ Identify technical steps and design considerations. 
✓ Learn how to quantitatively evaluate your system. 
   Optional: If interested, you may convert the literature review into a systematic review 
for publication. The subject leader will guide and co-author if pursued. However, this will 
not impact your coursework grades. 
 
 
 

Part II: Project Development and Evaluation (20%) 
Your must: 
✓ Design and implement  a computer vision -based system or algorithm using Python 
and OpenCV. 
✓ Either: 
o Improve upon an existing algorithm, or 
o Combine multiple known algorithms to develop a new approach. 
✓ Evaluate the system using relevant metrics identified during the literature review. 
✓ Clearly highlight differences from existing systems. 
✓ It is acceptable if the performance does not improve  if you analyse and explain the 
reasons behind it.
