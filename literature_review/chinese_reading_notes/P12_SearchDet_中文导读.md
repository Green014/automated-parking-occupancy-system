# P12 Search and Detect 中文导读

## 基本信息

- 英文标题：Search and Detect: Training-Free Long Tail Object Detection via Web-Image Retrieval
- 中文标题：Search and Detect：通过网页图像检索实现免训练长尾目标检测
- 会议年份：CVPR 2025
- 本地 PDF：`literature_review/papers/2025_CVPR_SearchDet.pdf`

## 一句话总结

这篇论文尝试用网页图像检索辅助长尾目标检测，适合处理少见类别或临时新增类别。

## 这篇论文解决什么问题

长尾检测指很多类别训练样本很少，模型难以识别。停车场中主要对象是车辆，但也可能遇到少见物体，例如临时施工设备、特殊车辆、障碍物或自定义管理对象。

Search and Detect 的思路是不用重新训练模型，而是借助网页图像检索来获得类别线索。

## 方法思路

论文把“搜索”和“检测”结合起来：当需要检测某个长尾类别时，从外部网页图像中检索相关视觉信息，再帮助检测模型识别目标。

可以理解为：

```text
输入目标类别名称
→ 检索网页图像
→ 获得类别视觉参考
→ 在目标图像中检测该类别
```

## 阅读重点

- 看 training-free 的含义。
- 看网页图像如何作为检测参考。
- 看 long-tail 类别上的提升。
- 思考这种方法是否适合实际监控系统。

## 对停车场项目的启发

如果停车场系统需要快速新增某类检测对象，比如 `charging station blocker`、`traffic barrel`、`snow pile`，而没有标注数据，这种思路有启发意义。

## 局限性

- 网页图像和真实停车场监控视角差异可能很大。
- 检索质量会影响检测结果。
- 对实时系统来说，在线检索可能增加延迟，实际部署可能需要离线缓存。

## 推荐精读程度

可选阅读。适合写开放类别和长尾对象检测的补充讨论。
