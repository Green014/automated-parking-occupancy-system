# P03 DiffMOT 中文导读

## 基本信息

- 英文标题：DiffMOT: A Real-time Diffusion-based Multiple Object Tracker with Non-linear Prediction
- 中文标题：DiffMOT：基于扩散模型非线性预测的实时多目标跟踪器
- 会议年份：CVPR 2024
- 本地 PDF：`literature_review/papers/2024_CVPR_DiffMOT.pdf`

## 一句话总结

这篇论文用扩散模型进行非线性运动预测，目的是让多目标跟踪器更好地处理复杂运动轨迹。

## 这篇论文解决什么问题

很多跟踪器使用线性运动假设，例如匀速模型或 Kalman Filter。但停车场中的车辆运动并不总是线性的：车辆会倒车、转弯、短暂停止、慢速挪动，甚至在车位附近进行多次调整。简单线性模型容易在这种情况下预测错误，导致目标关联失败。

DiffMOT 关注的就是非线性运动预测问题。

## 方法思路

论文引入扩散式运动预测模块，用于建模目标未来位置的不确定性和非线性变化。它不是只预测一个简单的线性位置，而是试图学习更复杂的运动分布。

对停车场项目可以理解为：

```text
车辆历史轨迹
→ 学习非线性运动模式
→ 预测下一帧或未来几帧位置
→ 帮助检测框和已有轨迹匹配
```

## 阅读重点

- 看它为什么认为传统线性运动模型不足。
- 看 diffusion-based prediction 如何接入 MOT pipeline。
- 看它是否保持 real-time。
- 看它在哪些数据集或场景上提升明显。

## 对停车场项目的启发

停车场车辆在入库、出库和绕行时经常出现非线性运动，因此 DiffMOT 对“车辆移动阶段”的跟踪很有参考价值。它可以降低车辆转弯、倒车时的 ID switch，从而帮助系统更准确地判断哪个车位正在被占用或释放。

## 局限性

- 扩散模型可能比传统 Kalman Filter 更重，需要测试实际推理速度。
- 停车场中大量车辆是静止的，非线性运动预测主要帮助动态车辆。
- 它仍然是通用 MOT 方法，不直接解决车位空间映射。

## 推荐精读程度

建议中等到精读。若你的系统重点是实时跟踪车辆进出车位，这篇很重要。
